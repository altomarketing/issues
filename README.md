# Centro de Issues

Acá se reportan bugs, ideas y consultas de todos nuestros productos.

## Productos incluidos
- **RadioNube Streamer**: Software profesional para transmisión de radio online (Icecast, Shoutcast, WebRTC WHIP).
- **Panel de RadioNube**: Panel de administración y streaming.
- **Panel de Cliente**: Área de autogestión de usuarios.

## Cómo reportar
Abrí una New Issue y elegí a qué producto pertenece.
